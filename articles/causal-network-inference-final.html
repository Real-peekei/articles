1. Motivation

The gene co-expression piece in this series asked which genes move together. This one asks a sharper question: when two proteins’ phosphorylation levels rise and fall together over time, does one of them actually drive the other, or are both just downstream of some third, shared trigger? Correlation can’t distinguish these cases — two proteins phosphorylated by the same upstream kinase will correlate strongly with each other even if neither one touches the other directly. Granger causality gives a concrete, testable answer: does knowing protein A’s past values improve the prediction of protein B’s future values, beyond what B’s own past already provides? If yes, A is said to “Granger-cause” B — not proof of biochemical mechanism, but a genuinely stronger claim than correlation, and one that respects time’s arrow in a way a correlation coefficient never can.

This piece builds a time-series phosphoproteomics dataset with a known causal structure — including a deliberate confound, two proteins that correlate strongly without any direct causal link between them — checks the assumption Granger causality actually depends on (stationarity, routinely skipped in public explanations of the method), and tests every directed pair with multiple-testing correction. It then compares the result against a plain correlation network to see what the causal framing does and doesn’t add, and finishes by re-running the test conditionally on the other proteins, which is the standard remedy for the artefacts a pairwise test produces. The result is more mixed than the method’s reputation suggests, and the mixed parts are the useful part.

2. Simulated Time-Series Dataset with Known Causal Ground Truth

Five proteins, forty timepoints. P1 is an upstream receptor-proximal phosphorylation event responding to a stimulus. P2 and P4 both respond to P1 directly — a genuine shared-cause structure. P3 responds to P2, extending the cascade one step further. P5 is pure noise, causally disconnected from everything, serving as a negative control. The critical pair to watch is P2 and P4: both driven by P1, so both will correlate with each other, but neither one causes the other.

stimulus = np.zeros(T)

P1 = np.zeros(T)
for t in range(1, T):

# P2: driven by P1 at lag 1
P2 = np.zeros(T)
for t in range(1, T):
    P2[t] = 0.75 * P1[t-1] + np.random.normal(0, noise_sd)

# P3: driven by P2 at lag 1 — cascade continues
P3 = np.zeros(T)
for t in range(1, T):
    P3[t] = 0.70 * P2[t-1] + np.random.normal(0, noise_sd)

# P4: ALSO driven by P1 at lag 1 — a separate branch off the same trigger.
# P4 will correlate with P2 (shared ancestor) with no direct causal link.
P4 = np.zeros(T)
for t in range(1, T):
    P4[t] = 0.65 * P1[t-1] + np.random.normal(0, noise_sd)

# P5: pure noise, no causal driver at all — negative control
P5 = np.random.normal(0, noise_sd, T)

4. Assumption Check: Stationarity

Granger causality is a statement about linear predictive relationships between time series, and the standard test for it assumes the series involved are stationary — their statistical properties (mean, variance) don’t drift over time.

ImportantNon-stationary series can manufacture fake causality

A series with a strong trend can produce Granger-significant results between completely unrelated variables, purely because both are drifting in the same direction over time, not because either one is actually informative about the other. This is a real, common failure mode in applied Granger causality work, not a theoretical footnote, and checking for it is not optional — P1 in this simulation was deliberately built with a persistent trend for exactly this reason, so the check below has something real to catch.

Show code

# Difference any series the ADF test flags as non-stationary (p >= 0.05)
# before proceeding — testing Granger causality on a non-stationary
# series risks exactly the spurious-relationship problem described above.
non_stationary = stationarity_results.loc[stationarity_results["p_value"] >= 0.05, "protein"].tolist()

data_for_gc = data_scaled.copy()
for col in non_stationary:
    data_for_gc[col] = data_scaled[col].diff()

data_for_gc = data_for_gc.dropna()

print(f"Series differenced for non-stationarity: {non_stationary if non_stationary else 'none'}")

The ADF test flagged four of the five series as non-stationary: P1 (p = 0.074), P2 (p = 0.124), P3 (p = 0.514), and P4 (p = 0.306). Only P5, the pure-noise control, came back clearly stationary (p = 1.2e-9). That split is what the simulation’s structure predicts: P1’s high persistence (an AR coefficient of 0.92) means it wanders rather than reverting to a fixed mean, and P2, P3, and P4 all inherit that wandering because each is a lagged linear function of something downstream of P1. One caution on reading the individual p-values: with only 40 timepoints the ADF test has limited power, so the differences among 0.07, 0.12, 0.31, and 0.51 shouldn’t be over-interpreted. What matters is the clear separation between the four wandering series and the one stationary control. All four were first-differenced before any Granger test ran, leaving 39 usable timepoints. Skipping that step is how spurious “causal” relationships between trending, unrelated variables end up in a published network.

5. Granger Causality Testing

Granger causality is directional, so every ordered pair needs its own test — does A cause B is a separate question from does B cause A, and both need answering independently. With 5 proteins, that’s 20 directed pairs. Testing at multiple lags and taking the strongest-supported lag per pair, followed by multiple-testing correction across all 20 tests, keeps the resulting network from being inflated by chance findings — exactly the same discipline any of the earlier pieces in this series applied to differential expression or pathway enrichment.

Show code 
proteins = data_for_gc.columns.tolist()
max_lag = 3
alpha = 0.05

results = []
errors_seen = set()
for target in proteins:
    for source in proteins:
        if target == source:
            continue
        pair_data = data_for_gc[[target, source]].values
        error_msg = None
        try:
            gc_result = grangercausalitytests(pair_data, max_lag)
            best_lag = min(
                range(1, max_lag + 1),
                key=lambda lag: gc_result[lag][0]["ssr_ftest"][1]
            )
            best_p = gc_result[best_lag][0]["ssr_ftest"][1]
        except Exception as e:
            best_lag, best_p = np.nan, 1.0
            error_msg = f"{type(e).__name__}: {e}"
            errors_seen.add(error_msg)
        results.append({
            "source": source, "target": target,
            "best_lag": best_lag, "p_value": best_p, "error": error_msg
        })

if errors_seen:
    print(f"{sum(r['error'] is not None for r in results)} of {len(results)} pairs raised an exception.")
    print("Distinct error message(s) seen:")
    for err in errors_seen:
        print(" -", err)
else:
    print("All pairs tested without error.")

gc_df = pd.DataFrame(results)
gc_df["p_adj"] = multipletests(gc_df["p_value"], method="fdr_bh")[1]
gc_df["significant"] = gc_df["p_adj"] < alpha

Eight of the 20 directed pairs survived FDR correction, which is more than the three true edges built into the simulation. Sorting them against the known ground truth:

  • Recovered true edges (3): P1→P2 (p_adj = 1.7e-12), P1→P4 (2.2e-12), and P2→P3 (1.4e-8). All three are the strongest results in the table by many orders of magnitude.
  • A true indirect path (1): P1→P3 (p_adj = 1.2e-5). P1 doesn’t drive P3 directly in the simulation, but it does drive P2, which drives P3. A bivariate test asks only whether P1’s past helps predict P3’s future, and it does, through the mediator. That’s correct behaviour for the test, but it shows that bivariate Granger causality can’t tell a direct edge from a mediated one.
  • Edges with no direct counterpart in the simulation (4): P4→P3 (2.4e-6), P2→P4 (0.017), P4→P5 (0.005), and P1→P5 (0.024). The first two are discussed in Section 7. The last two involve P5, which has no causal parents at all, so they are unambiguous false positives, and they survived a 5% FDR threshold.

The P5 false positives point to a specific weakness in how this analysis was set up. Each pair was tested at lags 1 through 3 and the smallest p-value was kept, but the FDR correction was applied only across the 20 pairs, not across the 60 pair-and-lag tests underneath them. Taking the best of three lags gives every pair three chances to look significant, and nothing in the correction accounts for that. The nominal 5% FDR threshold is therefore optimistic here. A cleaner design would either correct across all pair-and-lag combinations or fix the lag in advance using an information criterion such as AIC.

P1 comes out as the clear upstream hub: out-degree 4, in-degree 0. Nothing in the network drives it, and it drives everything else that has any incoming edge. That matches the ground truth, since P1 is the stimulus-responsive trigger at the top of the cascade. P3 is the mirror image, with in-degree 3 and out-degree 0, a pure downstream sink, which also matches the simulation because nothing depends on P3. So the coarse topology (who sits at the top, who sits at the bottom) was recovered correctly even though several individual edges in the middle were not.

The imperfections are concentrated in the middle of the network. P4 ends up with out-degree 2 (to P3 and P5), and neither edge reflects a direct link in the simulation. P5 has in-degree 2 when its true in-degree is 0. If this network were read edge by edge, it would overstate P4’s role as a regulator. Read at the level of “which proteins are upstream and which are downstream,” it is reliable.

The comparison does not show what the method’s reputation would lead you to expect, so the accurate reading matters more than the flattering one.

The first list, pairs that were strongly correlated but had no Granger edge in either direction, is empty. Every correlated pair also got a Granger edge, including the confounded pair P2–P4. The second list shows Granger flagging two pairs that correlation did not: P5–P1 and P5–P4, both involving the pure-noise control. On the narrow question of which pairs are connected at all, then, the causal framing added no correct exclusions and two false additions. Bivariate Granger did not “catch” the confound at the 5% FDR threshold.

It did two other things correlation cannot do:

  • Ranking. The single strongest correlation in the matrix is P2–P4 (r = 0.987), the confounded pair, higher than any of the three true edges (P1–P2 at 0.948, P1–P4 at 0.947, P2–P3 at 0.914). By correlation, the confound is the most convincing “relationship” in the dataset. By Granger evidence, the three smallest adjusted p-values (all below 1e-7) belong to exactly the three true edges, while P2→P4 sits seventh of eight significant edges at p_adj = 0.017, roughly ten orders of magnitude weaker than P1→P2. Read as a ranking rather than a yes/no threshold, the Granger output separated true edges from the confound far better than correlation did.
  • Direction. All three true edges came out with the correct direction (P1→P2, P1→P4, P2→P3). A correlation matrix is symmetric and has no way to express that.

The likely explanation for why P2→P4 cleared the threshold at all is P1’s persistence. P1 has an AR coefficient of 0.92, so its recent past is a good proxy for its present. Because P2 and P4 both track P1, P2’s lagged history carries usable information about the P1 trajectory that drives P4, which a bivariate test cannot distinguish from a direct P2→P4 effect. That is a hypothesis about this simulation, not something the bivariate test demonstrates. Section 8 tests it directly by conditioning on the other proteins.

8. Conditioning on the Other Proteins

The bivariate test asks whether A helps predict B on its own. A conditional test asks whether A still helps predict B after the past of every other protein has already been taken into account. Fitting all five series as a single vector autoregression (VAR) and testing each edge inside that joint model does exactly that, and it is the standard remedy for the shared-cause artefact suspected in Section 7: if P2’s apparent effect on P4 is only P2 acting as a proxy for P1, it should disappear once P1’s history is in the model.

This version also repairs the lag-selection weakness noted in Section 5. One lag order is chosen for the whole model by AIC, so there is no best-of-three-lags step, and the FDR correction covers the 20 tests actually performed.

Show code 
from statsmodels.tsa.api import VAR

var_model = VAR(data_for_gc)
order_selection = var_model.select_order(maxlags=3)
selected_lag = max(order_selection.selected_orders["aic"], 1)
var_fit = var_model.fit(selected_lag)
print(f"Lag order selected by AIC (floor of 1): {selected_lag}")

cond_results = []
cond_errors = set()
for target in proteins:
    for source in proteins:
        if target == source:
            continue
        try:
            test = var_fit.test_causality(target, [source], kind="f")
            p_val = test.pvalue
        except Exception as e:
            p_val = 1.0
            cond_errors.add(f"{type(e).__name__}: {e}")
        cond_results.append({"source": source, "target": target, "p_value": p_val})

if cond_errors:
    print("Errors raised during conditional testing:")
    for err in cond_errors:
        print(" -", err)
else:
    print("All conditional tests ran without error.")

WarningConditioning helps, but it is not a guarantee of causality

A conditional Granger test controls only for the variables that were measured. An unmeasured common driver, a nonlinear relationship, or a sampling interval coarser than the real biochemical timescale can each produce or hide an edge, and none of them can be detected from the test statistics alone. The joint model is also expensive in degrees of freedom: at lag L it estimates 5L + 1 coefficients per equation from 39 observations, so a conditional test has less power than a bivariate one, and a non-significant edge here means “not detectable at this sample size,” not “absent.” The edges that survive are best read as candidate regulatory relationships worth testing by perturbation, not as established mechanism.

9. Is Any of This Typical? A Replication Check

Everything above comes from one fixed random seed. That draw is exactly reproducible — rendering this document always regenerates the same numbers — but “reproducible” and “typical” are different properties. Before treating any pattern in Sections 5 through 8 as a property of the method rather than a property of this particular noise realization, it needs to be repeated across many independent draws of the same underlying causal structure.

def simulate_once(seed, T=40, noise_sd=0.4):
    rng = np.random.RandomState(seed)
    stim = np.zeros(T)
    stim[3:8] = 3.0
    p1 = np.zeros(T)
    for t in range(1, T):
        p1[t] = 0.92 * p1[t-1] + stim[t] + rng.normal(0, noise_sd)
    p2 = np.zeros(T); p3 = np.zeros(T); p4 = np.zeros(T)
    for t in range(1, T):
        p2[t] = 0.75 * p1[t-1] + rng.normal(0, noise_sd)
        p3[t] = 0.70 * p2[t-1] + rng.normal(0, noise_sd)
        p4[t] = 0.65 * p1[t-1] + rng.normal(0, noise_sd)
    p5 = rng.normal(0, noise_sd, T)
    df = pd.DataFrame({"P1": p1, "P2": p2, "P3": p3, "P4": p4, "P5": p5})
    return (df - df.mean()) / df.std()

def prep_for_granger(df_scaled):
    non_stat = [c for c in df_scaled.columns if adfuller(df_scaled[c])[1] >= 0.05]
    out = df_scaled.copy()
    for c in non_stat:
        out[c] = df_scaled[c].diff()
    return out.dropna()

def bivariate_edges(df, max_lag=3, alpha=0.05):
    rows = []
    for target in df.columns:
        for source in df.columns:
            if target == source:
                continue
            gc = grangercausalitytests(df[[target, source]].values, max_lag)
            p = min(gc[l][0]["ssr_ftest"][1] for l in range(1, max_lag + 1))
            rows.append((source, target, p))
    edf = pd.DataFrame(rows, columns=["source", "target", "p_value"])
    edf["sig"] = multipletests(edf["p_value"], method="fdr_bh")[1] < alpha
    return set(zip(edf.source[edf.sig], edf.target[edf.sig]))

def conditional_edges(df, maxlags=3, alpha=0.05):
    model = VAR(df)
    lag = max(model.select_order(maxlags=maxlags).selected_orders["aic"], 1)
    fit = model.fit(lag)
    rows = []
    for target in df.columns:
        for source in df.columns:
            if target == source:
                continue
            p = fit.test_causality(target, [source], kind="f").pvalue
            rows.append((source, target, p))
    edf = pd.DataFrame(rows, columns=["source", "target", "p_value"])
    edf["sig"] = multipletests(edf["p_value"], method="fdr_bh")[1] < alpha
    return set(zip(edf.source[edf.sig], edf.target[edf.sig])), lag

Reading the two columns side by side separates what this method does reliably from what depends on the noise draw. P1→P2 and P1→P4 are recovered at 100% by both approaches, never in doubt. P2→P3 is recovered at 100% by the bivariate test but only 71% once conditioned on the other proteins — a real, sizeable power cost, not a rounding difference, from asking the joint model to also account for P3, P4, and P5’s histories on just 39 observations.

The confound and the mediated path tell a sharper story, and the replication is what makes it possible to tell it with numbers instead of a hunch. Bivariate Granger causality flags the P2/P4 confound in 81% of replicates and the P4→P3 collinearity artefact in 99% — the single render walked through in Sections 5 through 7 was not a fluke, it was close to the typical case for both. Conditioning on the other proteins drops the confound rate to 10% and the P4→P3 rate to 4%, and does the same to the indirect P1→P3 edge, down to 4% from 100%. That is the replication-level confirmation that Section 8’s explanation — these are shared-cause and mediation artefacts, not direct effects — holds up rather than being a plausible story fitted after the fact.

One result does not fit the “conditioning fixes it” pattern: the false-edge rate into the noise control P5 sits at 10% for the bivariate test and 11% for the conditional one — essentially unchanged. Whatever is producing those two false positives in Section 5 (most likely the within-pair multiple-lag selection noted there), it is not the same shared-cause mechanism that conditioning corrects for, and conditioning on more variables does not fix a problem that was never about omitted variables in the first place. That is a useful negative result on its own: not every artefact in a Granger causality analysis has the same cause or the same remedy, and it is worth checking each one rather than assuming a single fix — conditioning — clears all of them.

Takeaways

ImportantKey findings
  • Stationarity was checked rather than assumed. Four of the five series (P1–P4) tested non-stationary and were differenced; only the pure-noise control was stationary. With 40 timepoints the ADF test has limited power, so the meaningful result is the separation between the wandering series and the control, not the individual p-values.
  • Bivariate Granger causality recovered all three true edges with the correct direction and correctly identified P1 as the upstream hub and P3 as a pure sink. It also reliably produces two artefacts that are not direct edges in the simulation — the mediated path P1→P3 (100% of 100 replicates) and the shared-cause pair P2/P4 (81%) — confirming these are systematic properties of the method on this structure, not a one-off feature of a single noisy draw.
  • Conditioning on every other protein in a joint VAR model is the textbook remedy, and the replication confirms it works exactly as the mechanism predicts: the confound rate drops from 81% to 10%, and the indirect and collinearity artefacts drop from 100% and 99% down to 4% each. The cost is real power — the true edge P2→P3, recovered 100% of the time bivariate, drops to 71% once every other protein is controlled for on only 39 observations.
  • Not every artefact has the same fix. A false-edge rate into the noise control P5 sits at 10% bivariate and 11% conditional — essentially unchanged by conditioning — meaning whatever produces it (most likely the uncorrected within-pair multiple-lag selection) is a different problem from the shared-cause confound, and needs a different remedy, not just “condition on more variables.”
  • Against a plain correlation network, Granger causality’s real advantages were direction (which a symmetric correlation matrix cannot express) and ranking — the three true edges had overwhelmingly the strongest statistical evidence, even though the confounded pair technically cleared the same significance threshold and had the single highest raw correlation in the dataset.
  • This analysis used simulated data so the ground truth would be checkable, and repeated the whole pipeline 100 times so no single conclusion rested on one noise draw. On real phosphoproteomics, the bash preprocessing in Section 3 would be needed to produce an evenly sampled time series in the first place, and unmeasured confounders would make every recovered edge a hypothesis for perturbation experiments rather than a finding.
